# Contributing

AI agents handle most maintenance and implementation in this repository. Reviewing an unsolicited pull request takes us longer than having an agent implement a proposal we have already reviewed.

## Propose a change

1. [Start a Discussion](../../discussions/new) describing the problem and the result you want.
2. Wait for a Mathematic maintainer to review the proposal.
3. If we accept it, a Mathematic maintainer or agent will implement the change and open the pull request.

Please do not open a pull request unless you are an organization member or repository collaborator. Approved maintenance bots may also open pull requests. We automatically close other pull requests and ask their authors to use Discussions instead.
