# noop

## Contributing

Have an idea or found a problem? [Start a
Discussion](../../discussions/new) and wait for a maintainer to review it. If
we decide to make the change, a Mathematic maintainer or agent will open the
pull request.

Please read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing a change. GitHub
restricts pull request creation to Mathematic maintainers and repository
collaborators with write, maintain, or admin access, plus authorized maintenance
agents.
