# Contributing

AI agents handle most maintenance and implementation in this repository.
Reviewing an unsolicited pull request takes us longer than having an agent
implement a proposal we have already reviewed.

## Propose a change

1. [Start a Discussion](../../discussions/new) describing the problem and the
   result you want.
2. Wait for a Mathematic maintainer to review the proposal.
3. If we accept it, a Mathematic maintainer or agent will implement the change
   and open the pull request.

GitHub restricts pull request creation to Mathematic maintainers and repository
collaborators with write, maintain, or admin access, plus authorized maintenance
agents. Everyone else should use the discussion process above.
